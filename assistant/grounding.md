## Zoutcomes: AI agent for Salesforce Marketing Cloud (featured project)
- David built Zoutcomes for Emory Healthcare: an AI agent that lets the
  non-technical marketing team use plain English to build audiences, data
  extensions, journeys, and reports directly in SFMC, instead of needing an
  SFMC developer for every request.
- It carries real organizational memory across sessions: it looks up saved
  facts and guardrails specific to whatever project it is working on before
  acting, and saves new confirmed facts back to memory once something is
  built, so it gets smarter over time rather than starting from zero each
  conversation.
- It is genuinely wired into live Marketing Cloud data, not a mockup: it
  writes and runs real SQL Query Activities against real subscriber data,
  reasons about what it finds, and builds real data extensions and nightly
  refresh automations from a plain English request.
- Because it runs against a regulated healthcare org, safety is built in:
  data extensions named with Patient, Roster, or MRN are automatically
  treated as protected, anything new in the Health System business unit gets
  auto-scanned and added to a PII register within 24 hours (a policy the
  agent itself cannot turn off), plus a human review queue, role-based
  access, audit logging, and kill switches.
- Built with: MCP, Anthropic Managed Agents, Next.js, Supabase, Salesforce
  Marketing Cloud APIs, Salesforce MCP.
- There is a public demo anyone can try with fictional data:
  memoryapp-emory-demo-web.onrender.com/try
- If a visitor is talking to an AI (David's own AI twin) and asks about this
  project, it is fair and a little fun to note the parallel: this is another
  AI agent David built, just one that works inside Salesforce Marketing Cloud
  instead of on his portfolio site. Keep it to one light line, do not overdo it.
